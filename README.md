# Romantic Land
《罗曼乐园》作品简介

《罗曼乐园》是一部一分钟治愈动画，讲述了一个关于孤独、坚持与希望的故事。
一个小男孩独自走在无边的沙漠里。他走了很久很久，遇见了一片绿洲。而绿洲的尽头，是一座永远不会关门的乐园。镜头缓缓推近，他终于走到了。“罗曼乐园，等你很久了。”
动画以“沙漠—绿地—乐园”三段式结构，用极简的画面和童话般的旁白，传递一个朴素的心念：每个孩子心里都有一片沙漠，但只要走得够远，就能遇见属于自己的乐园。 无论内心多么荒芜，只要不停下脚步，美好终会出现。

动画制作过程

一、资产生成与模型准备

1.生成建筑参考图：使用豆包生成游乐园建筑图片（城堡、摩天轮、旋转木马、商店、过山车、围栏等）。
2.图生3D模型：将上述图片上传至腾讯混元3D，通过AI生成对应的3D模型。动画中的三个小怪物也采用同样的图生3D方式完成。
3.角色模型与动画：主人公采用腾讯混元3D内置的“3D Studio”人物模型，进行绑骨、蒙皮，并制作走路、跑步、回头等动画，最后导出为FBX格式。

二、场景搭建与渲染

4.资产导入与整理：将人物模型（带动画）、小怪物模型（已绑定骨骼）、所有建筑模型导入Blender，统一调整比例和位置。
5.游乐园环境搭建：为世界环境添加天空纹理（参考网络教程），调整灯光和太阳光，完成游乐园场景。
6.游乐园运镜与渲染：通过摄像机+空物体组合实现旋转、推拉运镜。在时间轴上首尾打关键帧。为避免Blender崩溃，每次仅渲染约5秒的片段，分批导出。
7.沙漠与草地场景：新建场景，参考老师及网络教程，分别制作沙漠地形和草地地形。
8.自然环境搭建：同样添加天空纹理，调整灯光、太阳光适配地形，完成沙漠与草地场景。
9.角色与环境整合：导入带动画的人物模型，用摄像机+空物体进行运镜并打关键帧，渲染出沙漠和草地部分的动画。

三、后期剪辑

10.剪辑与合成：将所有渲染片段导入剪映，调整速度与运镜节奏，添加音频、文字及黑幕字幕，最终完成动画。

制作中遇见的问题

一、性能与稳定性问题

1.场景卡顿与渲染慢：游乐园场景中模型数量多以及模型面数大，调整位置大小时Blender操作非常卡顿，渲染速度极慢。
2.闪退与数据丢失：Blender频繁闪退，甚至出现黑屏，且时常来不及保存场景，导致进度丢失。

二、模型质量问题

1.图生3D结果不稳定：AI生成的3D模型有时出现破面、比例失调或细节丢失，需要反复生成。

三、解决尝试

1.分批渲染、降低预览渲染参数。
2.对不稳定模型尝试多次生成。
